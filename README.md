# LibraryProject

A Django web application for managing a library system, developed as part of the ALX Django Learning Lab.

## Description

This is the foundational Django project that serves as an introduction to Django development environment setup. The project demonstrates the basic Django project structure and development server setup.

## Features

- Django 5.2.5 framework
- Development server configuration
- Basic project structure following Django best practices
- Virtual environment setup for isolated development

## Setup Instructions

1. **Create and activate virtual environment:**
   ```bash
   python3 -m venv django_env
   source django_env/bin/activate
